🛠 Paso a paso: instalar el entorno
1

Instalar Flutter SDK

Ve a flutter.dev/docs/get-started/install, elige tu sistema operativo y sigue el instalador. Al finalizar corre: flutter doctor — debe mostrar todo en verde.

Tiempo estimado: 20–30 min

2

Instalar Android Studio

Descárgalo en developer.android.com/studio. Dentro de Android Studio, ve a Plugins e instala los plugins Flutter y Dart.

3

Crear emulador Android (AVD)

En Android Studio: Device Manager → Create Device. Elige Pixel 6 con API 34 (Android 14). Inícialo y verifica que arranca.

4

Crear tu primera app Flutter

Abre una terminal y ejecuta:
flutter create mi_primera_app
cd mi_primera_app
flutter run
Si ves el contador en el emulador, ¡lo lograste! 🎉

5

Subir el proyecto a GitHub

Crea una cuenta en github.com si no tienes. Crea un repositorio llamado et0126-mi-primera-app y sube tu proyecto. Ese repo llegará al primer corte.

No sabe usar Git? Busca: "Git en 15 minutos" en YouTube
